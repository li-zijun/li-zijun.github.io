# Zijun Li — Academic Website

A static academic website for Zijun Li, with three independent pages:

- `index.html`: biography, research interests, education, and research experience.
- `publications.html`: publications and the granted invention patent.
- `moments.html`: event photographs, dates, and locations.
- `patents.html`: redirect for older patent links.

## GitHub Pages

The GitHub account is `li-zijun`, and the repository is `li-zijun.github.io`. Its website address is `https://li-zijun.github.io/`. GitHub Pages serves the files from the `main` branch at the repository root.

Create a repository named `li-zijun.github.io`. Place this directory’s contents at the repository root, including `index.html`, `assets/`, and `.nojekyll`.

In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The website will be available at `https://li-zijun.github.io/` once GitHub finishes deployment. No domain purchase, build tool, or package installation is needed for this site.

See the [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart) and [publishing-source documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Editing

Edit the HTML files to update content, `styles.css` to change appearance, and `script.js` for the page directory, citation copying, shared likes, and older links. Each page has an in-page directory. Keep asset filenames and links consistent. The portrait, original paper figures, event photographs, and Chinese name signature are self-hosted under `assets/`.
