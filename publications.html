Small Models, Big Variances: Unveiling the Impact of Execution Environments on SLMs’ Security

Zijun Li, Tengfei Tu, Yuxin Lian, Zicheng Kong, Yiling Zhou, Aofan Liu, and Wenmin Li

Information and Communications Security (ICICS 2026), Part III, Lecture Notes in Computer Science, vol. 17216, 63–84, 2027. Published online 23 October 2026.

SecuDevSLM evaluates small language model security under mobile execution constraints. The study examines hallucination, jailbreak, and noise attacks, and analyzes how platform differences affect model robustness.

Aofan Liu, Haoxuan Li, Hongjian Xing, Yuguo Yin, Zijun Li, and Yiyan Qi

Proceedings of the AAAI Conference on Artificial Intelligence, 40(44), 37645–37653, 2026.

ChameleonAttack combines adaptive optimization in latent space with a semantic translation module to generate fluent adversarial text. The work investigates the robustness of financial language models to attacks that preserve linguistic meaning.

Software Vulnerability Detection Method Based on Abstract Syntax Tree Feature Migration (AST-FMVD)

Zi-jun Li, Tao Li, Hao-dong Chen, Qin Yu, Meng-qing Qiao, Lin Li, Jie Wang, Zhen-hua Wan, and Jing-han Song

Computer Technology and Development, 34(6), 81–88, June 2024.

AST-FMVD maps abstract syntax tree features between programming languages using semantic similarity and context-aware mappings. A Java-trained vulnerability detector is applied to Python code, exploring feature transfer without labeled target-domain training samples.
